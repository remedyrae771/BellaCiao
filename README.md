# Bella Ciao · Cucina

Кухонное приложение для итальянской траттории **Bella Ciao** (Алматы).
Работает в браузере на планшете или телефоне, ставится на главный экран как приложение (PWA) и работает без интернета.

## Возможности

- **Вход по личному коду.** У каждого повара свой 4-значный PIN. Коды хранятся только в виде хеша, после 5 ошибок вход блокируется на 30 секунд, после 10 минут бездействия выход происходит автоматически.
- **Роли:**
  - *Повар* видит чек-листы своей станции, все ТТК (по умолчанию открыты карты его станции) и ТБ.
  - *Су-шеф* видит все станции, редактирует ТТК и смотрит отчёт смены.
  - *Шеф-повар* может всё то же, а ещё управляет командой (добавляет поваров, выдаёт коды, отключает доступ) и редактирует пункты чек-листов.
- **Станции:** холодный цех, горячий цех (паста), горячий цех (гриль), раздача (су-шефы), пицца-станция, кондитерский цех.
- **Чек-листы:** открытие смены, работа во время смены, закрытие. Отметки ставятся каждый день заново, у каждой видно, кто и во сколько её поставил. История хранится 60 дней.
- **ТТК:** брутто и нетто, технология, подача, хранение, аллергены. Есть поиск по блюду или ингредиенту и пересчёт на нужное число порций (×5, ×10, ×20).
- **Техника безопасности:** общие разделы и разделы для конкретных станций. Сотрудник подтверждает «ознакомлен», шеф видит, кто прочитал.
- **Отчёт смены:** выполнение чек-листов по станциям за любую дату и список невыполненных пунктов.

## Коды по умолчанию (смените после первого входа!)

| Сотрудник | Код |
|---|---|
| Шеф-повар | 0000 |
| Су-шеф | 4444 |
| Холодный цех | 1111 |
| Паста | 2222 |
| Гриль | 3333 |
| Пицца | 5555 |
| Кондитер | 6666 |

Демо-сотрудников шеф может переименовать или удалить в разделе «Команда → Сотрудники».

## Запуск

Сборка не нужна, это статические файлы.

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Для работы на кухне выложите папку на любой статический хостинг с HTTPS (GitHub Pages, Netlify, Vercel). Затем откройте адрес на планшете и выберите «Добавить на главный экран».

## Структура

```
index.html        — точка входа
css/styles.css    — дизайн в стиле ресторана: голубой круг логотипа, коралловый, кобальтовая керамика, скатерть в клетку (Pacifico + Manrope)
js/data.js        — станции, стартовые чек-листы, ТТК, техника безопасности
js/app.js         — логика приложения
sw.js             — офлайн-режим
manifest.json     — установка как приложение
```

## Важно

- Данные хранятся **на устройстве** (localStorage). Если на кухне один общий планшет, это работает как есть. Чтобы синхронизировать несколько устройств и вести историю на сервере, нужен бэкенд (например, Supabase или Firebase). Это следующий шаг.
- ТТК в `js/data.js` — **примеры**. Замените их на утверждённые технологические карты ресторана: через приложение (роль шеф или су-шеф) или прямо в файле до первого запуска.
